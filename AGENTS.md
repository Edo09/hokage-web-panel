# Hokage Web Panel

Coach admin panel for the Hokage Coaching App. Product context and
infrastructure: see `AGENTS.md` in `Edo09/hokage-coaching-app`.

## Git workflow

- Work directly on the default branch (`main`); never create or switch branches.
- Commit finished changes to `main`, but never push to `origin/main` without the
  user's permission: ask before every push. Do not open PRs unless asked.
- `CLAUDE.md` and `AGENTS.md` hold the same instructions (Claude Code reads one,
  other agents the other): change both in the same commit.
